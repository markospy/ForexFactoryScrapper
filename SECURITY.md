# Security Policy

## Supported Versions

The following table lists active support windows for ForexFactoryScrapper releases.

| Version | Supported |
| :--- | :---: |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues, pull requests, or public discussions.

### Reporting Procedure

1. Email vulnerability details directly to the project maintainer at `atacanymc@gmail.com`.
2. Include a technical description of the vulnerability, affected endpoints, and reproducible steps or proof of concept.
3. You will receive an initial response acknowledging receipt within 48 hours.
4. Once verified, a patch will be prepared and released alongside a security advisory.
