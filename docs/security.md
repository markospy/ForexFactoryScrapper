# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

Do not open public GitHub issues for security vulnerabilities.

### Disclosure Process

1. Email vulnerability details directly to the project maintainer at `atacanymc@gmail.com`.
2. Provide reproduction steps, affected endpoints, and relevant logs.
3. You will receive an initial response acknowledging receipt within 48 hours.
4. Verified security patches will be published with a version bump and security advisory.
